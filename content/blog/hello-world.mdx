# Hello World

Posts live in `content/blog/` as MDX. The listing at [/blog](/blog) is generated
from Nextra's page map, so adding a file is all it takes — there is no index to
maintain.

## Frontmatter

| Field | Used for |
| --- | --- |
| `title` | Listing entry, page title, search result |
| `description` | Listing summary and meta description |
| `date` | Sort order (newest first) and the dateline |

A post without a `date` still appears, sorted after everything that has one.
